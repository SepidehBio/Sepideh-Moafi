Things I've built

Research software, machine learning pipelines, and small tools — mostly for biological and clinical data. Each project below is something I designed, wrote, tested, and tried to make reproducible.

LongiHealth

Reproducible ML for Hospital Outcome Prediction

A reproducible workflow for hospital outcome prediction using a demonstration dataset. Explicit preprocessing, leakage-aware design, automated testing, and containerization. The goal is to make the modelling process inspectable and to document its limitations honestly.

Python scikit-learn Docker pytest

Research prototype · not for clinical use

VariantLens

Evidence Retrieval for Rare Disease Variant Analysis

A command-line tool that combines variant input handling with evidence retrieval from ClinVar, gnomAD, MyVariant.info, and PubMed. Built to support computational investigation, not to replace clinical or genetic interpretation.

Python CLI ClinVar gnomAD

Research software prototype

SpatialPath

Reproducible Pipeline for Spatial Transcriptomics

End-to-end pipeline for 10x Visium data — quality control, normalization, PCA, Leiden clustering, Wilcoxon marker detection, and ridge-regression deconvolution. Validated on the 10x Genomics Human Breast Cancer dataset (4,869 spots, 21,349 genes).

Scanpy Squidpy Docker GitHub Actions

Manuscript ready for submission

ClinShift

Robustness & Calibration under Cross-Site Shift

A study of how discrimination and calibration move independently when clinical models transfer between sites. Found that at one site, AUROC improved from 0.73 to 0.77 while Expected Calibration Error rose from 0.06 to 0.29.

scikit-learn NumPy GitHub Actions

Manuscript ready for submission

scp-bench

Benchmarking Framework for Single-Cell ML

A benchmarking framework for evaluating machine learning models on single-cell data, with careful attention to evaluation design, dataset splits, and metric reporting.

Python Scanpy pytest

Open source · CI + Docker

SelfAwareLLM-Med

Reliability of Medical Language Models

Tests whether semantic self-consistency across multiple LLM generations predicts correctness on USMLE-style questions. Consistency correlates with accuracy (ρ = 0.29–0.36) but negatively with ROUGE-L, suggesting ROUGE-L is not a valid proxy for medical correctness.

Python Ollama pytest GitHub Actions

40+ tests · full pipeline in CI
