Selected Software

SelfAwareLLM-Med

Python package

A Python package evaluating whether semantic self-consistency predicts correctness on medical multiple-choice questions. Clean separation across data loading, model clients, consistency estimation, metrics, and reporting.

  • · ModelClient protocol with two implementations: an Ollama client and an offline FakeModelClient that makes the full test suite run without network access.
  • · 40+ unit tests covering consistency, metrics, data loaders, samplers, and error paths. Tests run in CI in under 40 seconds, with no model weights required.
  • · Two GitHub Actions workflows: ci.yml (lint + pytest on every push) and experiment.yml (manually-triggered full pipeline with model caching and artifact uploads).
  • · Full experiment pipeline: 250 questions × 3 sampling strategies = 750 model paths, 4,364 generation calls, 0 errors, 55 minutes on a free CPU-only GitHub runner.
Python pytest GitHub Actions Ollama

ClinShift

Reproducibility pipeline

A computational study with a fully automated pipeline that regenerates all reported results on every commit.

  • · Modular Python codebase organized into src/ for core logic, experiments/ for runnable scripts, scripts/ for utilities, and tests/ for unit tests.
  • · GitHub Actions workflow installs dependencies, runs each experiment in sequence, generates figures, and commits results back to the repository. Full pipeline completes in under one minute.
  • · Reproducibility enforced by passing random seeds explicitly to every stochastic component — cross-validation splitter, calibration splitter, estimators, and multivariate sub-sampling.
  • · Figures regenerate from saved JSON and CSV files alone, so results remain reproducible even if the source dataset becomes unavailable.
  • · Design decisions documented in docs/decisions.md, recording the evidence behind each choice and the conditions under which it should be revisited.
Python scikit-learn GitHub Actions pytest

SpatialPath

Python package

An open-source Python package that processes 10x Visium spatial transcriptomics data end to end, from raw count matrices to structured biological reports.

  • · Modular pipeline with isolated components for I/O, quality control, normalization, dimensionality reduction, clustering, marker detection, and deconvolution. Each module exposes a narrow, testable API.
  • · Centralized all hyperparameters in a single YAML configuration file, eliminating hidden defaults and enabling reproducible experiments.
  • · Docker containerization and GitHub Actions CI. Every commit triggers the full test suite; container image reproducible across platforms.
  • · Structured following modern Python standards: pyproject.toml with PEP 621 metadata, src/ layout, console entry point, optional dev dependencies, and pytest unit tests for every module.
Python Scanpy Docker GitHub Actions
