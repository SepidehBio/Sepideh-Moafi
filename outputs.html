Open Research Outputs

Models, data, and code

Everything I release is documented, licensed, and meant to be used by someone other than me. Most of it lives on HuggingFace and GitHub, with model cards, dataset documentation, and reproducible training configurations.

Models & Adapters

OmniLatent

Deep representation learning for transcriptomics

Autoencoder · PyTorch

An autoencoder for TCGA-BRCA transcriptomic data, released together with the processed dataset. The model card documents the architecture, training configuration, and known limitations.

· OmniLatent-TCGA-BRCA-model — trained autoencoder

· biolatent-brca-tcga — processed dataset (1.23k downloads, 406 likes)

PathogenAgentAI

Biomedical foundation models & datasets

BioGPT · LoRA

A BioGPT model fine-tuned on ClinVar-derived instruction data, released with its LoRA adapter and the instruction dataset itself. Built to make biomedical language model adaptation easier to inspect and reuse.

· Fine-tuned BioGPT model — ClinVar variant interpretation

· LoRA adapter — parameter-efficient adaptation layer

· Instruction dataset — ~20k ClinVar-derived examples

Datasets

ClinVar Instruction Set

~20,000 examples

An instruction-tuning dataset derived from ClinVar, used for biomedical language model adaptation. Split into training, validation, and test sets with no leakage across variants.

TCGA-BRCA RNA-seq

Processed matrix

Processed TCGA-BRCA RNA-seq matrix with clean splits, released alongside the OmniLatent autoencoder. Ready for representation learning experiments.
